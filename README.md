# ¡A Varear!

Juego incremental sobre la recogida de la aceituna: varea el olivo, lleva la aceituna a la tolva,
haz aceite de calidad, véndelo al mejor precio y mejora tu finca campaña tras campaña.

**Jugar:** abre la página de GitHub Pages de este repositorio.

- Funciona en el navegador del ordenador y del móvil.
- La partida se guarda en tu navegador: cada jugador tiene su propio progreso.
- Idiomas: español, English, français.

Hecho con [Godot Engine](https://godotengine.org) 4.6.
